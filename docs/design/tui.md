# Terminal User Interface

Kriterion-Engine provides a terminal user interface for inspecting and
manipulating evaluation tables.

## Interface principles

- Keyboard-first interaction.
- Clear separation between navigation and editing.
- Predictable operations.
- Minimal visual noise.
- Consistent feedback for user actions.

## Main areas

The interface is composed of:

- Table view
- Status / information area
- Command or action area
- Optional dialogs and overlays

The exact layout is documented with screenshots as the interface evolves.
